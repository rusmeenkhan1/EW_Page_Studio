Section metadata
description

Section metadata is a key-value paired configuration block type. Out of the box, you can use "style" and it will append to the section div as a class. Other options:

  • id, which turns into "id=help" (in this example) so that you can link to it using #help
  • background-image creates a new div.bg-image and puts the content div on top of it
  • background-color turns into an inline style and is applied to the outer section div (does not create a new div).
  • coming soon: use "background" for a gradient, also set as outer div style.

Any other key-value pairs will show as "data-" on the div.section which can be coded to invoke whatever custom behaviors that are needed.
