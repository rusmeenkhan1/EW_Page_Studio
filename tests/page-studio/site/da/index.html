How to test

  1. Open a page of this site in Experience Workspace.
  2. Open Page Studio from the library (Extensions).
  3. Click in a block, highlight a button or a value in a section's settings, or click an empty line and choose what to add.

Test pages

  • Blocks: every block, some with styles, to open in the Block view
  • Buttons: every button design, in text and inside blocks
  • Sections: sections with every kind of section setting
  • Variants: every variant of the main blocks, as the site shows it
  • Empty page: empty lines to add blocks, buttons and section settings
