Set the background, layout and spacing of the section your cursor is in. The page shows each change as you pick.

To add settings, click on an empty line in the section, outside the block. To change them, highlight a value in the section's settings table (Content view).

More than one section has this in its settings. Highlight a value of the table you want instead, such as its colour code.

Each change applies to the page as you pick. Undo: Ctrl+Z or ⌘Z.
